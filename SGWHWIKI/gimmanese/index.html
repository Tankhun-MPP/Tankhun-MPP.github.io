Introduction

Welcome to this game's conlang page. The conlang's name is Gimmanese (short: GN, GN-Romanized:kheing-poib, JP:ギマンニーズ, TH:ภาษาลูกเล่น)
Gimmanese is a language primarily used in this game, but I, the creator, typically also use it in real life for fun! (i let my friends try to read it) In Gimmanese, the conlang is influenced by some other language which are Thai (borrowed words, alphabet), English(grammar, borrowed words), Korean(character structure), Japanese(vowels, r alphabet character), and some more. For Gimmanese, some parts of the story (mostly post-game) use Gimmanese in some sort of scrolls or story.

Character Structure

In Gimmanese, the Structure follow pattern in the diagram shown here:
[WAIT FOR IMAGE PLEASE IM MAKING IT OMG]
The Character Structure has 4 types.

  1. 3-Letter (CVC): The character contains an initial, a vowel, and a final.
  2. 3-Letter-Special (CCVC): The character contains an initial, a cluster, a vowel, and a final.
  3. 2-Letter (CV): The character contains an initial, and a vowel.
  4. 2-Letter-Special (CCV): The character contains an initial, a cluster, and a vowel.

Where the Initial is usually at the top left, the Vowel is at the bottom, the final is usually at the top right, and the cluster is usually also at the top left, covering the inital while making the inital a bit smaller.
Character size and ratio do not matter in this language unless it makes it unreadable. So you can make it Long or Tall or like any rectangle you like.
