GIMMICKS

Introduction

Gimmicks are an important mechanic/part of Some Gimmick Will Happen.
Gimmicks basically mean that there is something special in a thing, like when there's a gimmick in a game, that means that the game is special from the others in a way.
In this game, gimmick is the thing that can cause the chaos in the game that can change everything in the world (locally)

How to get a gimmick?

In this game, you can get a random gimmick in every n seconds, where n starts at 30.
You're probably asking why is it n, but not 30. The reason is that gimmicks can change n too.
If you are a normal player, this is the only way to get a gimmick.
But for a person who has admin powers, you can get them by running a command, or opening the Gimmick Panel then selecting a gimmick to toggle them.
Why is there a Gimmick Panel? Solely for testing.

How to remove a gimmick?

A gimmick can be removed by a NPC named Jinx (NO PAGE RIGHT NOW)
You talk to Jinx to ask to remove a gimmick.
Though, he will actually pick a random gimmick to remove, and if you don't have that specific gimmick to be removed,
You will be punished by turning your head upside down. This is the only way to remove a gimmick as a normal player. For people who have admin powers, it is the same thing as to get a gimmick as a person who has admin powers.

The Properties of a Gimmick

For each gimmick in the game, it will have 6 properties:

  1. Name: The name of the gimmick
  2. Description: Short description that explains the gimmick simply
  3. Long Description: A Long Description that explains the gimmick, the pros, the cons, and funny notes. More below.
  4. Type: (ON 0.6.0P4 UPDATE) Explains how complex the gimmick is. More below.
  5. Passive Score Changes: It will change how much Passive Score you get every second.
  6. GimmickID: A unique number that represents the gimmick (usually used in the game code more than speech) More below.

Long Descriptions

A long description on a gimmick usually has the intro, the pros, the cons, the notes, and the passive score changes!
The intro will tell what the gimmick will do.
The pros and the cons will tell what are the good things and the bad things that happen from what the gimmick does.
The notes are basically extra notes for the gimmicks that are usually for no reason and funny
And the passive score changes tell what changes in the passive score you earn every second. Which includes base score and score. Where the operations on base score will happen before the ones on score.
It is usually in the style of this: 

[GIMMICK NAME] is a gimmick where [GIMMICK FUNCTION]
    •PROS
[GIMMICK PROS]
    •CONS
[GIMMICK CONS]
    •NOTES
[GIMMICK NOTES]
    •PASSIVE SCORE CHANGES
-[BASE SCORE OPERATION]
-[SCORE OPERATION]

Type

WARNING! This property is not avaliable yet on Version 0.6.0 Part 3, but will be avaliable on Version 0.6.0 Part 4.

In SGWH, there are 3 main types and many (not that many) special types.
Basically, in SGWH, there are 3 types and currently 1 special type.
A type tells how complex is the gimmick for understanding at a first glance. (super depending on my opinion but i will tell how it works) Though, if there is a special type with them, their meanings may change.
A special type tells what kind of gimmick it is.
Here are the three main types of gimmicks, and their meaning (if it is by themselves.)

  1. Basic: Simple to understand at a first glance, usually it's a type where it's a simple "A becomes B" or "When A happens, B will happen."
  2. Advanced: A bit harder and needs a bit more brain power to understand, usually it's a type where it's a tool or somethings that is not "A becomes B" but "You swim on the ground" or "You get a jumpscaring teddy bear."
  3. Complicated: Hard to understand, usually you would need to look at the long description to fully understand.

And here are the special types currently in the game.

  • Series: (+3 to types) The gimmick is in a series of 2 or more gimmicks. The types can either a, the meanings remain the same, and b, it is the difficulty.

GimmickID

A GimmickID is an unique number that represents the gimmick.
All gimmicks do not repeat the same GimmickID.
You can think GimmickID as like your Citizen/Personal ID of your Goverment (ID) Card for the gimmicks.
GimmickID is usually not talked about casually, but it actually used for the code.
If there are no GimmickIDs, there is no system that you can use, except if you use the gimmick names as the keys in the table but you cannot order it except Alphabetically which I actually don't like.
